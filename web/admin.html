SETUP GUIDE

配置教程

3 分钟完成接入：注册机器 → 选择策略 → 客户端只连 Manager

5 步 · 必读
01

登录管理端

打开 /admin 输入 MANAGER_ADMIN_KEY（来自 config/manager.env.local 或 /etc/opencode-manager.env）。该 Key 仅存于本浏览器 localStorage，用于 /admin/*。

http://MANAGER:8090/admin
# 输入 MANAGER_ADMIN_KEY
02

注册机器

点右上角 添加机器，填 机器 ID（如 sg-01）、名称、Base URL（Machine 桥根地址，不含 /v1）与 API Key（Machine 的 BRIDGE_KEY）。编辑时留空 Key 则保留原值。

Base URL: https://machine-01.example.internal
# 或 http://127.0.0.1:8080（本机 machine）
03

检查与启用

列表中点 检查 立即探测 /health 与 /v1/models；启用/停用 控制是否参与路由。异常卡会标 异常，冷却中显示剩余时间。

健康60 分钟冷却异常
04

选择调用策略

额度用尽后切换 会持续使用当前机器，收到 429/额度耗尽后才切到下一台；自动轮询 每次请求轮换，随机 随机挑选。限流冷却默认 60 分钟。

PUT /admin/routing
{ "strategy": "quota_failover", "rateLimitCooldownMs": 3600000 }
05

客户端接入

客户端 只连 Manager，用 MANAGER_API_KEY（与 Admin Key 不同）。兼容 OpenAI 的 /v1/models 与 /v1/chat/completions（含 SSE）。

curl http://MANAGER:8090/v1/chat/completions \
  -H "Authorization: Bearer $MANAGER_API_KEY" \
  -H "content-type: application/json" \
  -d '{"model":"provider/model","messages":[{"role":"user","content":"hello"}]}'

# Pi / OpenAI SDK 填：
# baseUrl = http://MANAGER:8090/v1
# apiKey  = MANAGER_API_KEY
06

验证与排障

先看顶部统计与最后更新时间戳，再各发一次普通与工具调用请求，确认工具在客户端本地执行。

健康检查GET /health → {"ok":true,"healthy":2}
模型列表GET /v1/models 需带 MANAGER_API_KEY
日志journalctl -u opencode-manager -n 100
密钥区分： MANAGER_ADMIN_KEY 管控制台，MANAGER_API_KEY 管客户端，BRIDGE_KEY 管 Machine。勿混用，不要提交到 Git。
